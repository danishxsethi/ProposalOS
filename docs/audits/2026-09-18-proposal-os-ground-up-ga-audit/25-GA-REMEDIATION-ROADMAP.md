# GA Remediation Roadmap

## Phase 0: freeze truth

Reauthenticate GCP; capture repo/default branch, build metadata, image digest, Cloud Run revisions/traffic, live DB migration/schema, worker identity, secrets references, Notion exports/URLs, and exact release manifest.

## Phase 1: immediate containment

Disable public proposal status mutation, public draft preview/actions, unsafe tenant header authority, wildcard API-key platform access, arbitrary ops-header quota bypass, unverified client exports, and production/mock email sends. Force manual review for degraded/unknown evidence and proposals.

## Phase 2: data and tenant correctness

Align Finding schema/contracts; add snapshot schema and ownership; centralize tenant context; fix all public/token routes; separate platform admin; run two-tenant IDOR/RLS matrix; validate migration replay.

## Phase 3: audit convergence

Disable/fix cache materialization; route every caller through AuditJob; normalize all module states; preserve partial findings; make unknown distinct from negative; persist final module/error/evidence state.

## Phase 4: diagnosis and claim integrity

Canonical input envelope, explicit degraded states, prompt-injection boundaries, versioned prompts/models, sentence/metric claim bindings, full rendered-section coverage.

## Phase 5: proposal and QA

One compiler, deterministic commercial facts, one publication predicate, redacted public projection, consistent hosted/PDF/PPTX expiry and artifact versioning.

## Phase 6: durable external effects

Consolidate email, durable idempotency, suppression, approval/simulation states, Stripe event/order/fulfillment state machine, retry/reconciliation, no real effects in test.

## Phase 7: production operations

Immutable build provenance, CI gates, observability/alerts, backup restore, incident/runbooks, live staging provider sandbox, and operator dashboards.

## Phase 8: qualification

Real authorized multi-vertical audits; measure evidence correctness, unsupported claims, intervention rate, latency, cost, failure recovery, load, accessibility, and tenant isolation. Release only a narrow controlled scope first.

## Phase 9: post-GA autonomy

Only after the narrow core is trusted: discovery, autonomous outreach, close, fulfillment, retention, outcome learning, white-label scale, and self-serve.

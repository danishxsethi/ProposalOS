## 1. Definitions

| Term            | Definition                                                               |
| --------------- | ------------------------------------------------------------------------ |
| "GDPR"          | General Data Protection Regulation (EU) 2016/679                         |
| "Personal Data" | Any information relating to an identified or identifiable natural person |
| "Processing"    | Any operation performed on Personal Data                                 |
| "Data Subject"  | The individual to whom Personal Data relates                             |
| "Subprocessor"  | Any processor engaged by the Data Processor                              |

## 2. Scope and Purpose

### 2.1 Purpose of Processing

ProposalOS will process Personal Data solely for the following purposes:

- Providing website audit services
- Generating proposals and reports
- Managing client communications
- Email outreach on behalf of the Controller

### 2.2 Categories of Data Subjects

- Controller's clients and prospects
- End users of Controller's services
- Controller's employees and contractors

### 2.3 Types of Personal Data

- Business contact information (name, email, phone)
- Business details (company name, address, website)
- Website audit data (URLs, performance metrics)
- Communication records

## 3. Obligations of the Data Controller

The Controller agrees to:

### 3.1 Lawful Basis

- Ensure a lawful basis for processing under GDPR Article 6
- Obtain necessary consents where required
- Maintain records of processing activities

### 3.2 Instructions

- Provide clear, documented instructions for processing
- Ensure instructions comply with applicable law
- Notify Processor of any changes to instructions

### 3.3 Data Subject Rights

- Respond to data subject requests
- Verify identity of requesting individuals
- Coordinate with Processor for technical implementation

## 4. Obligations of the Data Processor

ProposalOS agrees to:

### 4.1 Processing Instructions

- Process Personal Data only on documented instructions from Controller
- Not process data for any other purpose
- Notify Controller of any instruction conflicts with law

### 4.2 Confidentiality

- Ensure personnel are bound by confidentiality obligations
- Maintain confidentiality even after termination
- Limit access to Personal Data on need-to-know basis

### 4.3 Security Measures

Implement appropriate technical and organizational measures:

- Encryption in transit (TLS 1.3)
- Encryption at rest (AES-256)
- Access controls and authentication
- Regular security assessments
- Incident response procedures

### 4.4 Subprocessors

- Maintain list of authorized subprocessors
- Notify Controller of any new subprocessors
- Ensure subprocessors comply with this DPA
- Remain liable for subprocessor compliance

**Authorized Subprocessors:**

| Subprocessor          | Purpose            | Location |
| --------------------- | ------------------ | -------- |
| Google Cloud Platform | Hosting, storage   | US, EU   |
| Stripe                | Payment processing | US       |
| Resend                | Email delivery     | US       |
| Anthropic             | AI processing      | US       |
| OpenAI                | AI processing      | US       |
| Google                | AI processing      | US       |

### 4.5 Data Subject Rights Assistance

- Provide technical assistance for data subject requests
- Respond within 5 business days
- Provide data in machine-readable format
- Assist with rectification and erasure

### 4.6 Data Protection Impact Assessment

- Assist with DPIAs when required
- Provide information about processing activities
- Implement recommended safeguards

### 4.7 Breach Notification

- Notify Controller without undue delay (within 24 hours)
- Provide details of the breach
- Cooperate in investigation and remediation
- Notify affected data subjects if required

### 4.8 Return or Deletion

- Return or delete Personal Data upon termination
- Provide certification of deletion
- Retain only as required by law

### 4.9 Audit Rights

- Allow Controller to audit compliance
- Provide audit reports upon request
- Cooperate with regulatory investigations

## 5. International Data Transfers

### 5.1 Transfer Mechanisms

For transfers outside the EEA/UK:

- Standard Contractual Clauses (SCCs) apply
- Supplementary measures where required
- Documentation available upon request

### 5.2 Government Access Requests

Processor will:

- Notify Controller of any government access requests
- Challenge requests where legally permissible
- Limit disclosure to minimum required

## 6. Data Retention

### 6.1 Retention Period

Personal Data will be retained:

- As specified in the Service Agreement
- Based on Controller's plan tier (30/90/365 days)
- Or as required by applicable law

### 6.2 Deletion Schedule

| Data Type       | Deletion Timeline                |
| --------------- | -------------------------------- |
| Stale leads     | Automated after retention period |
| Account data    | 90 days after termination        |
| Payment records | 7 years (legal requirement)      |
| Audit logs      | 90 days                          |

## 7. Liability and Indemnification

### 7.1 Liability

- Each party is liable for its own GDPR violations
- Processor liable for breaches of this DPA
- Controller liable for unlawful instructions

### 7.2 Indemnification

Processor will indemnify Controller for:

- Processor's GDPR violations
- Unauthorized processing by Processor
- Processor's negligence or willful misconduct

## 8. Term and Termination

### 8.1 Term

This DPA remains in effect for the duration of the Service Agreement.

### 8.2 Termination

Upon termination:

- All Personal Data will be returned or deleted
- Deletion certified within 30 days
- Existing legal obligations survive

## 9. General Provisions

### 9.1 Amendments

This DPA may only be amended in writing signed by both parties.

### 9.2 Governing Law

This DPA is governed by [Jurisdiction] law.

### 9.3 Severability

If any provision is invalid, the remaining provisions remain in effect.

### 9.4 Entire Agreement

This DPA constitutes the entire agreement regarding data processing.

## Appendix A: Technical and Organizational Measures

### A.1 Encryption

- All data encrypted in transit using TLS 1.3
- All data encrypted at rest using AES-256
- Encryption keys managed securely

### A.2 Access Control

- Role-based access control (RBAC)
- Multi-factor authentication for admin access
- Regular access reviews
- Immediate revocation upon termination

### A.3 Physical Security

- Data centers with physical access controls
- 24/7 monitoring and logging
- Environmental controls

### A.4 Operational Security

- Security incident response plan
- Regular security training
- Background checks for personnel
- Change management procedures

### A.5 Data Minimization

- Only necessary data collected
- Automated deletion after retention period
- Pseudonymization where applicable

### A.6 Monitoring and Testing

- Regular vulnerability assessments
- Penetration testing
- Log monitoring and analysis
- Intrusion detection systems
